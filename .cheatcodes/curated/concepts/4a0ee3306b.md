# Symptom

A later edit or operation reports that the file's earlier read result is stale or that fresh anchors are required.

# Cause

The file was changed after the earlier read, so its content-derived anchors no longer represent the current on-disk content.

# Fix

Re-run read, grep, ast_search, or write on the file to obtain fresh anchors before relying on the contents or editing it.
