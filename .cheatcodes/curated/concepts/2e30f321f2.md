# Symptom

Validation fails because checkpoint.summary is missing and checkpoint contains an additional data property.

# Cause

The workflow_transition schema requires summary under checkpoint and disallows additional checkpoint properties.

# Fix

Send the checkpoint using the required summary property and omit unsupported additional properties such as data.
