# Symptom

Validation fails with: checkpoint.summary: must have required properties summary.

# Cause

The submitted checkpoint included data fields such as claim, method, and observation, but omitted the required summary field under checkpoint.summary.

# Fix

Include checkpoint.summary.summary as a string in the workflow_transition request; checkpoint.data alone is insufficient.
