# Symptom

Validation fails for tool workflow_transition with the message that checkpoint.summary must have required properties summary.

# Cause

The submitted checkpoint included data.plan but did not include the required summary property under checkpoint.summary.

# Fix

Include the required summary property under checkpoint.summary in the workflow_transition arguments.
